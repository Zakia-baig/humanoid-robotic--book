# Humanoid Robotics Book

A comprehensive guide to humanoid robotics, physical AI, ROS2, Gazebo, Isaac, Vision Language Action models, and more. This book provides both theoretical foundations and practical implementation guidance for humanoid robotics development.

## Features

- 13 comprehensive chapters covering all aspects of humanoid robotics
- Multi-language support (English and Urdu)
- Interactive content with code examples
- Personalization features for customized learning
- Authentication system with background questions
- Responsive design for all device sizes

## Technology Stack

- [Docusaurus](https://docusaurus.io/) - Static site generator
- [React](https://reactjs.org/) - Component-based UI
- [MDX](https://mdxjs.com/) - Markdown with JSX
- [Better Auth](https://better-auth.com/) - Authentication system
- [GitHub Pages](https://pages.github.com/) - Hosting

## Getting Started

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd robotic-book
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
